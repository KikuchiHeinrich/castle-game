# 《城堡》牌型顺序

出战区里的牌能凑成什么牌型，就按什么牌型比。**一共 22 档，从大到小如下。**

> 唯一权威来源是 `packages/shared/src/handTypes.ts`（顺序是设计者手工排定的，刻意不按张数排，**请勿调整**）。

## 摊牌怎么比（依次比，前一项分出胜负就不再往下看）

1. **牌型档位** —— 上表排名大的赢
2. **杂牌少者胜** —— 出战区里**没参与牌型**的牌越少越赢（"掺水"）
3. **牌型内最大牌** —— 都相同时比较牌型里最大的那张点数
4. **花色** —— 最后才比花色：**黑桃 ♠ > 梅花 ♣ > 红桃 ♥ > 方片 ♦**

## 五个容易记混的点

- **不按张数排。** 四条（4 张）压得住六同花（6 张）；3+3 压四条；葫芦（5 张）比三对（6 张）大。
- **顺子里 A 可高可低。** `10 J Q K A` 是最大的顺子，`A 2 3 4 5` 是最小的顺子，都算顺子。A 也能用来凑对子/三条。
- **"同花顺"要同时满足同花 + 连续**，只满足一半的牌型低很多。
- **多打牌是有代价的。** 杂牌只在第 ② 条判据上惩罚你；多出牌的唯一好处是**抬高押注上限**（上限 = 出战区牌数 × 筹码倍数）。
- **花色是最后的兜底判据**，前面三项全平了才轮到它。

# 四席位流程验收记录

记录日期：2026-10-17。以下内容为主代理实际浏览器观察结果。

## 验收证据

- 源预览：Vite `5174` 连接当前源服务器 `3210`。
- 桌面 `1280×720`：四个固定头像与公开字段均正常显示；轮到其他玩家操作后，桌面牌仍保持显示。
- 真实第五名玩家加入被拒绝，提示“最多4”。
- 四个真实客户端的准备流程：准备显示 `1/4`，取消后 `0/4`；三人准备时为 `3/4`，北位已弃牌，仍等待其确认；北位确认后进入第 2 回合。
- 回放暂停在首张牌：南位已翻开 `1` 张，其余玩家均为 `0`；全部组成牌/杂牌标记为 `0`；随后全员翻牌阶段保持暂停，可继续播放。
- 移动端同源 iframe 的真实尺寸 `360×640` 与 `320×568` 均可见：CSS 修复后，四个角色各自的出战区均显示两张牌，准备按钮完整显示。

最终前端验证：`9` 个文件共 `110` 个测试通过，三组 TypeScript 检查全部通过；服务端和客户端生产构建于 `15:37` 通过。

移动端 `320×568` 每人六张牌正常出牌已实测：四个出战区各含 `6` 个 DOM 节点，`field clientWidth === scrollWidth`，依次为 `[178, 80, 80, 178]`，所有牌槽均位于牌桌内；空手牌修复后的截图为 `mobile-320-six-card-play.png`。

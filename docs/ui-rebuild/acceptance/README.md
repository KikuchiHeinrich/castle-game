## 流程

六个真实客户端完成三轮出牌、追加牌段、跟注、同意摊牌、结算与回合恢复；另验证六张牌防守及锁定。

- 所有六席头像及大头像均可打开详情，Escape/关闭按钮会返回触发头像的焦点。
- 打开法师详情后从另一客户端加牌，详情由三张更新为六张，押注由3更新为4；两张公开牌与四张暗牌数量正确。
- 单段六张牌在320像素详情中自动换成两行，一张公开牌、五张暗牌均完整可见。见 [详情数据](active-stage/details-single-six.json)。
- 本人提交后，下位玩家已轮到时，舞台仍保留正在出牌的本人及人物动作；落牌后才切换，下位人物与牌一致，飞牌清理完成。
- 比较榜首为防守者、奖池归另一玩家时，榜首骑士的六张牌仍显示在骑士名下，结果把奖池计给守卫。见 [比较榜首记录](active-stage/comparison-leader.json)。
- 最终结算即时隐藏自己的出战条，手牌区为 display:none，dock 仅19–20.5px。320像素下六行结果完整可见；长内容留在舞台内滚动。见 [最终结算数据](active-stage/settlement-final.json)。
- 第4回合恢复六张手牌、正常操作区，见 [恢复记录](active-stage/round-restored.json)。

开发中热更新产生过临时日志；最终版本的第3回合与随后恢复未出现新增控制台错误。
